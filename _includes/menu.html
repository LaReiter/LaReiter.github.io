{%- comment -%} Renders a nav list. Two kinds of entry are supported: {ref: about, icon: user} -> internal page. Resolved to the page whose front matter has this `ref` and a `lang` matching the current page, so the nav follows the language. {title:, url:, icon:} -> literal link. Used by site.external in the footer. {%- endcomment -%} {%- assign cur_lang = page.lang | default: site.lang | default: "en" -%}
{%- for item in include.menu -%} {%- if item.ref -%} {%- assign node = site.pages | where: "ref", item.ref | where: "lang", cur_lang | first -%} {%- assign url = node.url -%} {%- assign title = node.title -%} {%- else -%} {%- assign url = item.url -%} {%- assign title = item.title -%} {%- endif -%} {%- if url -%} {%- if item.icon -%}{%- else -%}{{ title }}{%- endif -%} {%- endif -%} {%- endfor -%}
